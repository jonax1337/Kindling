A few things
worth knowing.

Is this still vanilla survival?

Kindling preserves vanilla and Leaf behaviour by default. No smaller world, mob-spawn throttling or distant-entity tick skipping is required for its default optimizations.

Can I switch from Leaf or Paper?

Kindling keeps Leaf's configuration and Paper plugin compatibility. Back up your worlds before replacing the server JAR. Existing Leaf configurations stay intact; review the recommended settings when migrating.

Do I need a separate pregenerator?

No. Kindling includes /pregen with start, pause, resume, cancel and status commands. It can also prepare each dimension automatically when configured.

Where are the docs and source?

The repository README covers setup and configuration. The measurement notes explain the tests. Source, issues and releases live on GitHub.
